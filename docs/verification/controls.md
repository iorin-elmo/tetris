# 操作の確認記録

初期キー・パッド割当は `apps/web/src/settings/store.ts` にあり、設計書のPROJECT_DEFAULTを使用しています。原作PC/Switch等の公式デフォルトと一致すると断言しません。

Chrome/Edge/Firefoxのキーボードによる移動/HOLD/ドロップ/メニュー、設定永続化、連続再試行を自動確認。ChromiumではGamepad APIの模擬Xbox入力によるHOLD・Startメニュー・切断も確認しました。

物理パッドの機種・OS・ブラウザ・有線/無線・デッドゾーン・体感遅延は、実機検証後に追記してください。ブラウザの認識前にボタンを押す操作と、フォーカス喪失時の停止を確認してください。
